Linux and Motorola 68000 Emulator

I read an article that someone had managed to get Linux running on a Sega MegaDrive which has a Motorola 68000 CPU and no MMU. This inspired me to attempt something similar with the CP/M-68K emulator I made last year.

It turns out that not many changes are needed to the emulator. Primarily just adding a timer that gives an interrupt that can be acted upon. This is crucial for any multi-tasking operating system like Linux. I went for the simplest possible solution by just counting CPU instructions to tick the timer, since the emulator doesn't count individual cycles, but it works well enough. I also discovered a kind of bug with the STOP instruction, which was not detected previously when just running CP/M-68K; that it does not advance the program counter! This had to be fixed to avoid getting stuck. The STOP instruction will also now call usleep() to relax the host CPU since Linux on the 68000 uses this by default when idle and just waiting for interrupts. The necessary changes are included in version 0.2 that can be downloaded here or from the public GitHub, GitLab or Codeberg repositories.

To make a compatible Linux kernel and root filesystem I used a newer version 2026.8 version of Buildroot. This comes with Linux kernel version 7.1 by default which is also used. I had to make drivers for the timer, console and disks that are provided by the emulator by using the same TRAP mechanism as the custom CP/M-68K BIOS uses. The drivers were loosely based on the existing drivers to support Atari ST emulators that are already present in the kernel. Note that a patch is needed on the GCC compiler to avoid it creating unaligned memory accesses for the original Motorola 68000. The complete Buildroot configuration with patches can be downloaded here.

Building is done like this:

cd buildroot-2026.08
tar -xvzf cpm68emu-linux.tar.gz
make cpm68emu_defconfig
make -j32


For convenience, here is also a pre-built kernel and root filesystem. To start the cpm68emu emulator with Linux, use the following arguments:

./cpm68emu -b vmlinux.srec -e 0x400 rootfs.cramfs
